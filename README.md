# PulseDesk Bot

Telegram-бот для приёма и первичной обработки заявок от клиентов.

## Что умеет
- Пошагово запрашивает у пользователя имя, описание задачи и контакт для связи.
- Формирует структурированную карточку заявки и мгновенно пересылает её администратору/менеджеру в Telegram.
- Возвращает пользователя в главное меню после отправки.# PulseDesk-bot
